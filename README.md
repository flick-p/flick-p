### 👋 About me

I design and build backend systems that stay stable under real production load — from payment platforms processing live transactions to decentralised wallet infrastructure handling on-chain transfers. 3+ years shipping fintech payment rails and blockchain infrastructure in **Go**.

- 💳 **Fintech payments** — Bakong wallet transfers, local bank transactions, KHQR payments (built a custom KHQR decoder from scratch in Go)
- ⛓️ **Blockchain / DApps** — TRON network integration, USDT transfers, wallet credit collection, energy delegation
- 🛠️ **Core engineering** — API design (REST/gRPC), database schema design, safe migration versioning, containerised deployments
